# ORF Podcasts OPML

An OPML collection of podcasts listed on [sound.orf.at/podcasts/sender](https://sound.orf.at/podcasts/sender).

## About

* Podcasts are grouped and sorted by station.
* The OPML file is updated semi-regularly.
* Can be imported into podcast apps and other software that supports OPML subscriptions.
